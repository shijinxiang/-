# 东金决战

《东金决战》是一个基于 Godot 4.3 的 2D 横版像素风双人动作格斗原型。

## 1.0 版本

当前 `v1.0` 是可运行的本地双人核心玩法版本，包含：

- 练习模式、双人对战、合作闯关
- 金：拖鞋普攻、投掷拖鞋、拖鞋拾取、臭气气团
- 东：徒手攻击、三格怒气、卡皮巴拉手雷、满怒喷火
- 移动、跳跃、二段跳、冲刺
- 对战回合、90 秒倒计时、三局两胜、比分结算
- 合作敌人、首领、倒地救援、检查点和失败重试
- Godot headless 工程检查与战斗冒烟测试

## 运行环境

- Windows 10/11
- Godot 4.3 stable
- 逻辑分辨率 640×360，默认窗口 1280×720

仓库不包含 Godot 引擎二进制文件。请从 Godot 官方渠道下载 Godot 4.3 stable：

```text
Godot_v4.3-stable_win64.exe --path game
```

## 操作

玩家 1（金）：A/D 移动，Space 跳跃，Shift 冲刺，J 普攻，K 投掷拖鞋，L 大招，F 拾取/救援。

玩家 2（东）：←/→ 移动，↑ 跳跃，Tab 冲刺，1 普攻，2 手雷，3 大招，4 拾取/救援。

Esc 打开个人暂停菜单。

## 自检

在 Windows 项目根目录运行：

```bat
tools\run_selfcheck.bat
```

脚本会依次检查工程解析、主菜单启动、战斗冒烟测试和合作场景启动。看到 `SELFTEST_PASS` 才表示本次自检链全部通过。

## 当前边界

1. 当前 1.0 是本地双人版本，尚未实现 ENet 真实双机联网、房间创建/加入或公网直连。
2. 角色和敌人当前主要使用程序绘制表现；仓库保留了原始 PNG 参考素材，但尚未完成透明抠图、逐帧动作和正式素材接入。
3. 尚未提供 Windows 导出包；需在安装 Godot 4.3 的环境中打开工程运行。
4. 未将未验证的公网、性能和导出结果描述为已完成。
