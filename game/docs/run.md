# 《东金决战》运行说明

## 环境

- Godot 4.3 stable
- Windows 10/11
- 工程目录：`game/`
- 逻辑分辨率：640×360；默认窗口：1280×720

## 启动

使用项目内的 Godot 4.3：

```text
Godot_v4.3-stable_win64.exe --path game
```

也可以在 Godot 编辑器中导入 `game/project.godot` 后运行。主菜单进入“开始移动”即可打开当前场景。

## 当前流程

- 主菜单提供“开始移动”“设置 / 人物招式”和“退出”。
- 当前场景使用朝阳天桥背景，金与东同时在场景中移动。
- 金使用 A / D 移动、Space 跳跃；东使用方向键移动、上方向键跳跃。
- 运行中按 Esc 打开暂停界面。
- 暂停界面提供“继续游戏”“人物招式”和“返回菜单”；按“人物招式”可查看当前按键说明。
- 菜单和暂停界面的按键提示使用纯色按键块，未依赖贴图。

## 默认操作

### 金

- A / D：左右移动
- Space：跳跃

### 东

- ← / →：左右移动
- ↑：跳跃

### 通用

- Esc：打开或关闭暂停界面

## 一键工程自检

在项目根目录执行：

```bat
tools\\run_selfcheck.bat
```

自检依次执行：

1. Godot 工程与脚本解析检查
2. 主菜单无界面启动检查
3. 移动场景无界面启动检查
4. `scenes/menu.tscn` 与 `scenes/arena.tscn` 文件检查

看到 `SELFTEST_PASS` 才表示本次自检链全部通过。
