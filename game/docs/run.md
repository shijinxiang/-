# 《东金决战》运行说明

## 环境

- Godot 4.3 stable
- Windows 10/11
- 工程目录：`game/`
- 逻辑分辨率：640×360；默认窗口：1280×720

## 启动

使用项目内的 Godot 4.3：

```text
Godot_v4.3-stable_win64.exe --path game
```

也可以在 Godot 编辑器中导入 `game/project.godot` 后运行。

## 模式

- **练习**：金与东同时可控，场内有训练假人。
- **对战**：金与东本地双人对战，100 生命、90 秒、三局两胜。
- **合作**：金与东组队，包含三波敌人、投掷敌人、首领、倒地与救援、检查点和失败重试。

## 默认操作

### 玩家 1（金）

- A / D：左右移动
- Space：跳跃 / 二段跳
- Shift：冲刺
- J：拖鞋拍击
- K：投掷拖鞋
- L：臭气冲天
- F：拾取拖鞋 / 救援队友
- Esc：菜单

### 玩家 2（东）

- ← / →：左右移动
- ↑：跳跃 / 二段跳
- Shift：冲刺
- 1：徒手攻击
- 2：卡皮手雷（消耗 100 怒气）
- 3：怒火喷射（满 300 怒气）
- 4：拾取 / 救援
- Esc：菜单

## 一键工程自检

在项目根目录双击或执行：

```bat
tools\\run_selfcheck.bat
```

自检依次执行：

1. Godot 工程与脚本解析检查
2. 主菜单无界面启动检查
3. `tests/combat_smoke.tscn` 战斗冒烟测试（带退出码断言）
4. 合作场景无界面启动检查

看到 `SELFTEST_PASS` 才表示本次自检链全部通过。
